# 江流 · 长江漫游

在线游玩：https://ichenwin.github.io/yangtze/

一个不用图片贴图、录音、外部模型或动作捕捉文件的程序化长江游泳游戏。五段沿江意象：重庆、宜昌、武汉、南京、上海。使用本地打包的 Three.js r170（MIT，许可证见 `dist/vendor/THREE-LICENSE.txt`），不依赖外部 CDN。

## 第二版

- 连续曲面躯干，程序化头部、泳帽、泳镜、手掌、手指和脚趾。
- 三种游姿采用分阶段轨迹和双骨骼逆向运动学，保持肢段长度；自由泳包含高肘回臂、身体滚转和侧向换气，蛙泳包含抱水、前伸、收腿和蹬夹，仰泳包含交替划臂和打腿。
- 人物随水面高度浮动，手入水时产生粒子水花，尾流采用细线波纹。
- 自动前游。主界面仅保留菜单、游姿、潜水三个操作按钮。城市与偏好设置收进可滚动菜单。
- 手机支持单指拖动转向、向上推加速、松手恢复体力、双击潜水；包括横竖屏布局、安全区、动态视口高度、Pointer Capture 与指针取消处理。
- 手机限制初始渲染分辨率和水面网格密度；持续慢帧时降低分辨率。进入后台暂停并静音。
- 城市有沿江护岸、阶梯、路灯、建筑窗格，重复几何通过 GPU 实例化绘制。

## 操作

进入后自动游泳，无需一直按键。

| 设备 | 转向 | 加速 | 潜水 | 其他 |
|---|---|---|---|---|
| 手机 | 按住画面左右拖动 | 拖动时向上推；松手恢复体力 | 双击画面或右下角按钮 | 左下角换游姿，右上角菜单 |
| 桌面 | A / D 或左右方向键；也可拖动 | W / 上方向键；Shift 冲刺 | 空格或右下角按钮 | E 换游姿，V 换视角，P / Esc 菜单，S 慢漂 |

每段 800 米，游完进入下一站；穿过三枚光环发现生灵、恢复体力，错过的光环会重置到前方。刷新页面重新开始，无存档。

## 本地运行

在本目录执行：

```sh
python3 -m http.server 8765 --directory dist
```

打开 http://localhost:8765 。需要支持 WebGL 2 的浏览器。

## CPU 与 GPU 分工

- CPU：固定种子生成地形/建筑，更新玩法、体力、生物路径与骨骼 IK。
- GPU：计算波浪、法线、噪声、菲涅耳近似、太阳反光、尾流和河床焦散；实例化绘制静态重复几何。
- Web Audio：噪声缓冲、低通滤波、振荡器与包络生成水声和音乐。

水面与游姿采用艺术化近似，不是完整流体或人体生物力学模拟，也不用于游泳教学。城市只是意象，非实景地图；坐标仅用于城市标注。

## 核查与参考

灵感来自 [Cold Smoke](https://github.com/huiskylabs/cold-smoke) 的程序化运行时生成方式。本项目未复制其游戏代码或动作数据。原作本身已使用 WebGPU / WebGL2，而非全由 CPU 绘图。它的仓库有宣传图片、字体与从视频提取的动作数值；“程序化生成”并不意味着没有设计或参考。

第二版完成 540 帧三种游姿的有限坐标检查，以及 300 组双骨骼长度检查；最大肢段长度误差小于 1e-8。浏览器检查覆盖桌面、320×568、390×844 竖屏和 844×390 横屏；包括拖动、双击潜水、游姿、菜单暂停与城市切换。尚未在实体 iPhone/Android 上测试。
